# models/

```
item/<Wikidata id>/      one particular wreck or underwater site
class/<Wikidata id>/     every ship of a vessel class (e.g. a U-boat type)
vehicle/<Wikidata id>/   every aircraft of a type (e.g. an airliner model)
```

Each folder: `model.glb` + `meta.json` (+ `preview.jpg`, + optional `model_built.glb`).
Rules: [docs/MODEL_SPEC.md](../docs/MODEL_SPEC.md) · [docs/MODEL_SPEC.es.md](../docs/MODEL_SPEC.es.md).
